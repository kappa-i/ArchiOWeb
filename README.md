## Prérequis

- Node.js ≥ 22.9
- MongoDB 8.0 (pas la 9), installé selon le [guide du cours](https://github.com/MediaComem/comem-archioweb/blob/main/guides/install-mongodb.md) — sous Windows : installateur officiel + MongoDB Shell

## Installation

```sh
npm ci
cp .env.example .env
```
